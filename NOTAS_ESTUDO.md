# NOTAS DE ESTUDO

## 1. O que difere um Projeto de Software de um Script/Código isolado?

Depois da pesquisa, entendi que um projeto de software vai muito além de apenas escrever código. Ele começa com um planejamento, possui objetivos bem definidos e passa por várias etapas até ser entregue. Também envolve documentação, organização e, muitas vezes, o trabalho de uma equipe inteira. Já um script ou código isolado costuma ser bem mais simples, sendo desenvolvido para resolver uma necessidade específica, sem toda essa estrutura.

---

## 2. Ciclo de Vida Básico

### Levantamento de Requisitos / Escopo

Essa é a etapa em que se busca entender o problema que precisa ser resolvido. Nela são levantadas as necessidades do cliente e definidas as funcionalidades que o sistema deverá ter. Um escopo bem elaborado serve como um guia para o restante do projeto.

### Desenvolvimento / Codificação

Com o planejamento pronto, começa a criação do sistema. Os desenvolvedores transformam as ideias em código, implementando cada funcionalidade prevista no projeto.

### Testes / Qualidade

Após o desenvolvimento, o software passa por testes para verificar se tudo funciona corretamente. Essa etapa ajuda a encontrar erros, corrigir falhas e garantir que o sistema seja confiável antes de chegar ao usuário.

### Entrega / Implantação

É quando o software finalmente é disponibilizado para uso. Dependendo do projeto, essa fase também inclui instalação, configurações e orientações para que o cliente consiga utilizar o sistema sem dificuldades.

---

## 3. Por que definir um escopo fechado antes de iniciar a codificação é importante?

Na minha opinião, começar a programar sem um escopo definido é como construir uma casa sem uma planta. A equipe pode acabar perdendo tempo fazendo alterações que poderiam ter sido evitadas. Quando o escopo está bem definido, todos sabem o que deve ser desenvolvido, o planejamento fica mais organizado e as chances de atrasos e retrabalho diminuem bastante.
