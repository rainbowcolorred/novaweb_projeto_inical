## Arquivos
- `index.html`: estrutura do formulário e cabeçalho.
- `style.css`: estilos dos campos e pseudo-classes.
- `script.js`: habilita e desabilita os campos.

## Como executar
1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador.

## Funcionamento
Os quatro campos começam desabilitados. Ao clicar no botão Habilitar correspondente, o JavaScript habilita o campo e coloca o foco nele. Quando o campo perde o foco, o evento `blur` desabilita o campo novamente.

## Pseudo-classes demonstradas
- `:disabled`: campos desabilitados.
- `:required`: campos obrigatórios.
- `:focus`: campo em foco.
- `:read-only`: campos somente leitura.
- `:autofocus`: estilo de campo com foco automático, caso esse atributo seja utilizado.
