# Aula 13 — Elementos Avançados de Formulário

## Arquivos
- `perfil.html`: estrutura da página de perfil.
- `estilos.css`: aparência e organização visual.
- `script.js`: validações e efeitos com JavaScript.
- `perfil.webp`: imagem ilustrativa fornecida no exemplo da atividade.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code.
3. Abra `perfil.html` no navegador (ou use a extensão Live Server).

## Conteúdos utilizados
- `radio`: permite escolher apenas uma opção.
- `checkbox`: permite marcar várias opções.
- `select`: cria uma lista suspensa.
- `textarea`: permite escrever um texto longo.
- JavaScript: valida os campos obrigatórios, mostra mensagens, conta caracteres e formata o telefone.

Observação: a validação acontece no navegador. O formulário não envia nem armazena dados em um servidor.
